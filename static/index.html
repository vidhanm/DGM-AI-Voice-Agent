How It Works

1. Baseline Agent

Start with a hand-crafted prompt designed for debt collection conversations. This serves as generation 0.

2. Evolution

The system creates variations, tests them against personas, evaluates performance, and selects the best for the next generation.

3. Best Agent

After multiple generations, you get an optimized agent that performs better than the baseline on all metrics.
